# 모닝 루틴 30

매일 아침 30분짜리 건강 루틴을 타이머로 안내해주는 React 웹앱입니다.
기록은 브라우저 localStorage에 저장됩니다 (MVP, 서버 없음).

## 루틴 구성 (6단계 x 5분)

1. 스트레칭
2. 손/귀/발 마사지
3. 봉체조
4. 스쿼트
5. 팔굽혀펴기
6. 호흡/마무리

## 실행

```bash
npm install
npm run dev
```

## 기능

- 단계별 자동 전환 타이머 (일시정지/다음 단계 건너뛰기)
- 완료 시 효과음 및 완료 화면
- 오늘 완료 여부, 연속일(스트릭), 최근 5주 캘린더 기록
